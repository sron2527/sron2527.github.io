ลิขิตไทย (LikhitThai Studio) — รุ่นลูกค้า 1.0.3

ไฟล์ติดตั้ง
1) LikhitThai Studio-1.0.3-nsis.exe = ตัวติดตั้ง Windows 64-bit
2) LikhitThai Studio-1.0.3-portable.exe = รุ่นไม่ต้องติดตั้ง

วิธีติดตั้ง
1. ดาวน์โหลดไฟล์ nsis.exe
2. ดับเบิลคลิก แล้วกด Next ตามขั้นตอน
3. เลือกตำแหน่งติดตั้ง แล้วกด Install
4. เปิดโปรแกรมจากไอคอน LikhitThai Studio บน Desktop

วิธีใช้
1. เปิดโปรแกรมและใส่ Gemini API Key ของผู้ใช้เอง
2. เริ่มสร้างบท สร้างภาพ และสร้างวิดีโอได้ตามปกติ
3. ระบบวิดีโอใช้ Gemini Omni 1.2 Flash รองรับความยาว 3–15 วินาที
4. ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อใช้งาน AI

หมายเหตุ
- รุ่นนี้ไม่มีโฆษณา AdSense และ Hilltop Ads
- โปรแกรมไม่ฝัง API Key ของผู้พัฒนา ลูกค้าต้องใช้ API Key ของตนเอง
- ค่าใช้งาน Gemini API คิดตามบัญชี Google AI ของลูกค้า
- แอปเดสก์ท็อปเปิดหน้าแอปจากอินเทอร์เน็ต จึงต้องออนไลน์เพื่อใช้งานและรับการปรับปรุงล่าสุด
