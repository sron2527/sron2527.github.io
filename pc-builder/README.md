# PC BUILDER — Webcam Edition

เกมต้นแบบสื่อการเรียนรู้เรื่องอุปกรณ์และการประกอบคอมพิวเตอร์

## ทดลองเล่น
https://sron2527.github.io/pc-builder/

## วิธีเล่น
1. เปิดเว็บไซต์ด้วย Chrome หรือ Edge รุ่นปัจจุบัน
2. กด “เปิดกล้องและเริ่มเล่น” และอนุญาตสิทธิ์กล้อง
3. ยกมือให้อยู่ในกรอบกล้อง
4. เลื่อนมือเพื่อเลื่อนตัวชี้
5. จีบนิ้วโป้งกับนิ้วชี้เพื่อหยิบอุปกรณ์ แล้วคลายนิ้วเพื่อวางลงในช่องที่ตรงกัน
6. แข่งติดตั้งอุปกรณ์ทั้ง 4 ชิ้นภายใน 15 วินาที\n7. วางถูกได้ +100 คะแนน วางผิดหัก 10 คะแนน และติดตั้งครบจะได้โบนัสจากเวลาที่เหลือ\n8. เปิด/ปิดเสียงได้จากปุ่มเสียง และกด “เล่นอีกครั้ง” เพื่อเริ่มรอบใหม่

## เทคโนโลยี
- MediaPipe Tasks Vision / Hand Landmarker
- JavaScript ES Modules
- HTML + CSS
- GitHub Pages

## โครงสร้าง
- `index.html` — หน้าจอเกม
- `style.css` — รูปแบบและองค์ประกอบภาพ
- `app.js` — เปิดเว็บแคม ตรวจจับมือ และตรรกะการหยิบวาง

## หมายเหตุรุ่นทดลอง
รุ่นนี้เป็น V0.2 เพิ่มภารกิจจับเวลา 15 วินาที ระบบคะแนน เสียงเอฟเฟกต์ที่สร้างในเบราว์เซอร์ และหน้าสรุปผล สำหรับทดสอบกล้องและท่าทางจีบนิ้ว โดยใช้ภาพประกอบอุปกรณ์แบบ CSS และแผงเมนบอร์ดจำลอง ยังไม่ใช่ฉาก 3D เต็มรูปแบบ รุ่นถัดไปจะเพิ่มโมเดลอุปกรณ์ 3D/ภาพถ่ายสมจริง การติดตั้งในเคส และระบบคำอธิบายความรู้

การประมวลผลภาพจากกล้องทำงานในเบราว์เซอร์ของผู้เล่น ไม่มีระบบอัปโหลดหรือจัดเก็บวิดีโอ
