# PC BUILDER — Webcam Edition

เกมต้นแบบสื่อการเรียนรู้เรื่องอุปกรณ์และการประกอบคอมพิวเตอร์

## ทดลองเล่น
https://sron2527.github.io/pc-builder/

## วิธีเล่น
1. เปิดเว็บไซต์ด้วย Chrome หรือ Edge รุ่นปัจจุบัน
2. กด “เปิดกล้องเพื่อใช้งานมือ” และอนุญาตสิทธิ์กล้อง
3. ยกมือให้อยู่ในกรอบกล้อง แล้วเลื่อนปลายนิ้วไปที่ปุ่ม “เริ่มภารกิจ”
4. ค้างตัวชี้บนปุ่มเริ่มภารกิจ 3 วินาที เพื่อเริ่มรอบ
5. เมื่อนับเวลาเริ่มแล้ว มีเวลา 20 วินาทีในการติดตั้ง CPU, RAM, M.2 SSD, GPU, CPU Cooler, Power Supply, HDD และ Case Fan
6. จีบนิ้วโป้งกับนิ้วชี้เพื่อหยิบอุปกรณ์ แล้วคลายนิ้วเพื่อวางในตำแหน่งที่ตรงกัน
7. วางถูกได้ +100 คะแนน วางผิดหัก 10 คะแนน และติดตั้งครบจะได้โบนัสจากเวลาที่เหลือ
8. เปิด/ปิดเสียงได้จากปุ่มเสียง และกด “เล่นอีกครั้ง” เพื่อเริ่มรอบใหม่

## เทคโนโลยี
- MediaPipe Tasks Vision / Hand Landmarker
- JavaScript ES Modules
- HTML + CSS
- GitHub Pages

## โครงสร้าง
- `index.html` — หน้าจอเกม
- `style.css` — รูปแบบและองค์ประกอบภาพ
- `app.js` — เปิดเว็บแคม ตรวจจับมือ และตรรกะการหยิบวาง

## หมายเหตุรุ่นทดลอง
รุ่น V0.3 เพิ่มอุปกรณ์เป็น 8 รายการ ระบบเริ่มเกมด้วยการค้างตัวชี้บนปุ่ม 3 วินาที และเวลาแข่งขัน 20 วินาที ภาพชิ้นส่วนในรุ่นนี้เป็นภาพประกอบ CSS ที่ปรับรายละเอียดให้ชัดขึ้น ยังไม่ใช่ภาพถ่ายผลิตภัณฑ์จริงหรือโมเดล 3D เต็มรูปแบบ

การติดตั้งอุปกรณ์บางรายการเป็นการจำลองพื้นที่ภายในเคสเพื่อฝึกจำแนกชิ้นส่วน ไม่ใช่ตำแหน่งประกอบบนเมนบอร์ดทั้งหมด

การประมวลผลภาพจากกล้องทำงานในเบราว์เซอร์ของผู้เล่น ไม่มีระบบอัปโหลดหรือจัดเก็บวิดีโอ
